# Incident Report Analysis – ICMP Flood Attack

![Focus](https://img.shields.io/badge/Focus-Incident%20Response-blue)
![Framework](https://img.shields.io/badge/Framework-NIST%20CSF-green)

## Overview

A cybersecurity case study analyzing an ICMP flood attack that disrupted a fictional company's internal network for approximately two hours.

The exercise focuses on assessing the incident and developing a network security improvement plan using the NIST Cybersecurity Framework (CSF).

## Key Areas

- ICMP flood and Denial of Service (DoS) attack analysis
- Firewall configuration and traffic filtering
- Network monitoring and anomaly detection
- IDS/IPS implementation
- Incident response and recovery planning
- Application of the NIST CSF functions

## Framework

The analysis follows the five NIST Cybersecurity Framework functions:

**Identify | Protect | Detect | Respond | Recover**

## Skills Demonstrated

Network security fundamentals, incident analysis, risk identification and incident response planning.
