# SQL Filtering for Security Analysis

![Focus](https://img.shields.io/badge/Focus-Security%20Analysis-blue)
![Technology](https://img.shields.io/badge/Technology-SQL-green)

## Overview

A practical SQL exercise focused on filtering security-related data to investigate suspicious login activity and identify employee accounts requiring security updates.

## Tasks Performed

- Retrieved failed login attempts outside business hours.
- Filtered login activity by specific dates.
- Identified login attempts originating outside Mexico.
- Retrieved employees from specific departments and office locations.
- Filtered employee records based on department exclusions.

## SQL Concepts & Commands

| SQL Feature | Purpose |
|---|---|
| `SELECT` | Retrieve data from database tables |
| `WHERE` | Filter records based on conditions |
| `AND` / `OR` | Combine multiple filtering conditions |
| `NOT` | Exclude specific results |
| `LIKE` | Match text patterns |
| `%` | Wildcard for pattern matching |

## Skills Demonstrated

SQL querying, security log analysis, data filtering, suspicious login investigation and employee data analysis.
