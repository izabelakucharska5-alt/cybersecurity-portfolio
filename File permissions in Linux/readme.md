# Linux File Permissions Management

![Focus](https://img.shields.io/badge/Focus-Linux%20Security-blue)
![Skills](https://img.shields.io/badge/Skills-Access%20Control-green)

## Overview

A hands-on Linux security exercise focused on inspecting and modifying file and directory permissions to enforce appropriate access control.

## Tasks Performed

- Inspected file and directory permissions using `ls -la`.
- Analyzed Linux permission strings (read, write, execute).
- Modified file permissions using `chmod`.
- Removed unnecessary write permissions from other users.
- Updated permissions on hidden files.
- Restricted directory access to a specific user.

## Commands Used

| Command | Purpose |
|---|---|
| `ls -la` | List files, hidden files and permissions |
| `chmod` | Modify file and directory permissions |

## Skills Demonstrated

Linux command line, file system security, access control, permission management and Linux security fundamentals.
