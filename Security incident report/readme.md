![Analysis](https://img.shields.io/badge/Type-Traffic%20Analysis-green)

## Overview

A practical network investigation focused on analyzing DNS and ICMP traffic to identify the cause of connectivity issues affecting a website.

## Investigation Tasks

- Analyzed DNS queries over UDP.
- Examined ICMP error messages.
- Investigated UDP port 53 connectivity issues.
- Used tcpdump packet captures to examine network traffic.
- Identified potential causes of DNS communication failures.
- Considered DNS misconfiguration, firewall rules and DoS attacks as possible causes.

## Tools & Technologies

- **tcpdump** – Network packet analysis
- **DNS** – Domain name resolution
- **ICMP** – Network error analysis
- **UDP** – Transport protocol analysis

## Skills Demonstrated

Network traffic analysis, DNS troubleshooting, protocol analysis, incident investigation and security event documentation.
