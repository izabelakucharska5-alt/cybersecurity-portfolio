![Analysis](https://img.shields.io/badge/Type-Incident%20Analysis-green)

## Overview

A practical security incident analysis involving a compromised website, malicious file delivery and suspicious network traffic.

The exercise focuses on identifying the attack mechanism, analyzing network traffic and documenting security findings.

## Investigation Tasks

- Analyzed network traffic using TCPDump logs.
- Identified HTTP communication between the client and web servers.
- Examined DNS queries and IP address changes.
- Investigated suspicious website redirection.
- Analyzed a potential malware delivery scenario.
- Identified a possible brute-force attack against an administrative account.
- Proposed security improvements and remediation measures.

## Tools & Technologies

- **tcpdump** – Network traffic analysis
- **DNS** – Domain resolution analysis
- **HTTP** – Web traffic investigation

## Key Security Concepts

Network traffic analysis, website compromise, malware delivery, brute-force attacks, incident investigation and security remediation.
